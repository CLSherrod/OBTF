# Use these as starting points, not rules.
# Org conventions used here:
# - Headlines begin with one or more stars.
# - Tags sit at the end of a headline as :tag:.
# - Inactive timestamps use square brackets, e.g. [2026-01-16 Fri].
# - Keep everything chronological unless there is a strong reason not to.

* Minimal Daily :template:
Use this when you want the least possible structure.

#+begin_src org
* 2026-01-16 Friday
[2026-01-16 Fri]

- Walked by the water.
- Paid electrician.
- Felt clear in the afternoon.
#+end_src
